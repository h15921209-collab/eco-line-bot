【最新發言稿 · 就業冷卻 vs 10Y長端發債溢價背馳】 即時連線推演

美國經濟當前正處於「就業數據失速與長端利率失控」的雙重背馳臨界點，這不僅是聯準會貨幣政策的死穴，更是全球大宗商品與實體產業鏈定價權的重大變數。

非農就業連續負增長（-2.3 萬人）伴隨 4.1% 的失業率，顯示勞動力市場結構性聘僱動能降溫；然而 CPI 3.4% 與核心 PCE 3.3% 的黏性，封殺了聯準會激進寬鬆的空間。當前最荒謬的背馳定價在於：2Y 美債殖利率 (3.961%) 領先反映預防性降息，但 10Y 美債殖利率 (4.784%) 卻因財政赤字天量發債帶來的「期限溢價」持續飆升，導致 10Y-2Y 利差大幅走陡至 +82.3 bps。

這不是經濟強勁擴張的訊號，而是典型的「熊市走陡 (Bear Steepener)」——市場正對美國財政部無底線的發債規模與長端流動性風險進行強制性重定價。短端降息並未同等緩解長端實體融資成本！長端利差支撐美元指數 (DXY 98.75)，使跨國企業的海外借貸利率與原料採購剛性成本持續高懸。

◆ 歷史鏡像：1980 年代初期「沃爾克時刻」後的財政擴張博弈
• 共通點：財政赤字天量發債掩蓋了貨幣政策的寬鬆效果，長債殖利率脫離景氣基本面而由發債供需失衡主導。
• 本次核心差異：AI 基礎建設帶動結構性電力與機房設備剛性資本支出，使得終端利基需求具備定價權，與 80 年代全面性需求萎縮迥然不同。

在 Google 試算表點選 擴充功能 ➔ Apps Script，貼上下方代碼並設定每日定時觸發，即可終身免費自動封存每一天的歷史數據：

function archiveDailyData() {
  var ss = SpreadsheetApp.getActiveSpreadsheet();
  var live = ss.getSheets()[0];
  var hist = ss.getSheetByName("歷史永久庫") || ss.insertSheet("歷史永久庫");
  if (hist.getLastRow() === 0) hist.appendRow(live.getRange(1, 1, 1, live.getLastColumn()).getValues()[0]);
  var todayData = live.getRange(2, 1, 1, live.getLastColumn()).getValues()[0];
  var lastDate = hist.getLastRow() > 1 ? hist.getRange(hist.getLastRow(), 1).getValue() : "";
  if (lastDate != todayData[0]) hist.appendRow(todayData);
}
